# 衡准 V1 实施与验收矩阵

依据用户提供的 `Hengzhun_V1_Design_Spec.docx` 及随后提供的同源机器附件。本文记录工程合同与验收边界，不是收益结果。

## 源文档与实现决定

- 策略名称：衡准 V1；策略标识：`HENGZHUN_TWAP_VALUE_V1`；设计版本：`1.0.0`。
- DOCX SHA256：`670000328944e87f444f96b56d7181803ad0499466c29316eeab3ab192a8f68c`。
- 完整机器附件已提供；先前“缺少附件”的检查结果已经解除。保留原始 `acceptance_matrix.json` 的 `NOT_RUN`，实际执行结果写独立报告，不改写原设计。
- 当前项目为 Python，用户已确认按 Python 接入现有系统。§15 的接口、金额精度、数据因果和状态不变量保持；没有宣称交付 Java 二进制或跨语言 Java 验证。
- 默认 `RECORD`；允许模式只有 RECORD、REPLAY、PAPER。任何真实签名、报单、撤单、领取接口都不可供本策略调用。现有四个策略的运行和资金不接入衡准钱包协调器，不伪称已完成共享组合验收。
- 不能使用旧 Paper 的确认计时、预算、最小量简化、零成交重试或重启取消规则替代本书规则。

## 参数与口径

参数登记表共 94 项：runtime 7、market 5、data 8、prior 15、calibration 21、entry 12、risk 8、paper 8、research 10。S1/S2/S3 是另外的三个预登记情景。修改参数必须生成新的配置摘要与实验版本。

- 同时保存 `source_at`、首次 `received_at`、`boot_id`、`ingest_seq`；内部 UTC epoch 毫秒。不能用轮询时刻替换真实到达时间。
- `tau_model=T-t_obs` 与 `tau_wall=T-decision_at` 分离。最后一分钟已知积分仅到 t_obs，普通 spot 做积分，官方 TWAP 只用作基准及代理误差校验。
- 只按有承诺的序列检查缺口；同源同时间异值必须记录冲突。流恢复及钱包对账后连续 10 秒健康才允许新增风险。
- 校准模型不可伪造；UNFITTED 不得被零系数替代。数据不足只允许 RECORD 与显式 UNCALIBRATED 先验影子。
- 运行在独立 $100 模拟经济空间，固定 $5 含费上限，不缩单、不凑最小量。每期一个持久化意图，拒绝/零成交/发送前中止都不恢复资格。
- 预占和资格原子化；UNKNOWN 或 SUBMITTING 后崩溃不得当成没有成交，不能重发。成交在撮合时计风险，确认延迟从撮合后起算 12 秒。
- 官方结果最终、订单终态、全部成交现金与净份额确认、无未知敞口四项同时满足才经济结算；领取计时从该确认时刻起 60 秒。
- G24 是过去 24 小时负净损益的总额，赢单不抵扣；G24 + 未决风险 + 下一单预算 ≤ $10。成本占用 ≤ $10、全钱包最多一个风险槽、潜在领取市场数 ≤ 2。
- 有效净值高水位回撤达到 15% 锁定新增；缺失估值不能按零价触发回撤锁。重启、跨日和改配置不清锁。

## 研究实现边界

研究模块提供完整 28/7/7 周步进切分、市场组和标签可见性、每市场总权重一的 Brier/logloss、完整日成对循环移动块 bootstrap，以及分层门槛判定。统计函数使用 double；输入经济结果用十进制字符串，报告不把影子收益合并为 $100 账户收益。

`research_pipeline.py` 连接真实训练器与完整因果回放器：每折只用其训练窗，验证决定是否发布；全部测试周在同一情景内保留一个连续钱包。B0 是现金，B2 使用登记的原始先验信号与统一执行，B3 仅作概率比较。B1 使用可取得的冻结当前修正版主账户代码：统一风控信号比较与原配置完整账户分别回放、分别报告；没有完整源代码/配置/输入的历史原版保持 BASELINE_UNAVAILABLE。原始 schema 不允许把未校准对照冒充校准策略，因此另设严格的 `BaselineOrderIntent` 扩展合同，见 [对照合同](hengzhun-v1-baseline-contract.md)。

概率指标置信区间沿用 20,000 次、UTC 日成对循环块 L=3、种子 20261106 的诊断协议，并在报告中命名。正文要求置信范围但未唯一规定概率指标区间算法；该选择不改变 G2 的点估计 0.01 容差。经济主检验及 L=1、3、7 敏感性按 §19。

`ClockMonitor` 只查询配置的 NTP 服务器，从不调整 OS 时钟。无可用证据、过期、无同步标志或时钟跳跃返回 CLOCK_UNVERIFIED；偏移上界包含 |offset|、RTT/2、root dispersion、非负 root delay/2 和精度余量。普通 NTP 未做密码学认证，输出 `authenticated=false` 明示信任边界；配置服务器信任不等同于 NTS 认证。
