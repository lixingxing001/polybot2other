## 保留与调整

| 项目 | 本次 Paper |
|---|---|
| 概率数学 | 原衡准零漂移 TWAP 正态先验；最终一分钟使用已观察积分，缺口不插值 |
| 波动估计 | 优先 120/600 秒因果网格；样本不足时使用冻结的现有历史方差，界面明示来源 |
| 概率校准 | 暂不训练 logistic，不伪造 bootstrap 分位数；两侧先验各减 0.02，仍标为未校准 |
| 训练与时间门槛 | 本试验暂不要求 3,000 训练市场、20 完整日及独立 7 天验证；原严格模式门槛不变 |
| 实盘接入审计 | 读取公开市场资产、手续费、精度、最低份额和真实开盘 TWAP；不宣称 IV01–03 全部通过 |
| 时钟与时效 | NTP 250ms 上界不作为本试验开仓门槛；仍拒绝未来数据、过期价格和盘口；源年龄 3 秒、接收年龄 2 秒 |
| 其他数据检查 | 双侧盘口源时间差 ≤500ms；历史网格源年龄 3 秒、接收年龄 2.5 秒；积分最大缺口 2 秒 |
| 入场 | 剩余 30–90 秒，预计到达至少剩 25 秒；卖一 ≥0.20、限价 ≤0.70、价差 ≤0.02、最多追一个 tick |
| 价值筛选 | 两侧独立评估；含费每份净优势 ≥0.03、ROI ≥5%；价值相等不选方向 |
| 资金 | 独立 $100，单笔含费预算 $5，最多 1 笔未决风险、2 个含待领取市场，成本占用 ≤$10 |
| 损失限制 | 24h 已实现负损益＋未决风险＋新预算 ≤$10；有效净值回撤 15% 停新增；另保留 $15 本轮损失上限 |
| 执行假设 | S2：2 秒到达、25% 可见深度；仅按提交后、到达时可见盘口模拟 FAK，部分成交后取消剩余 |
| 费用假设 | 当前公开曲线，现金加费保守近似，逐档向上取整；不是实际份额扣费精度的完整验收 |
| 确认与结算 | 撮合后 12 秒确认，持有到已核验官方终局，再等 60 秒模拟领取；没有配对、追单或止盈止损 |
| 每期限制 | 一次持久化意图；零成交和重启都不再对同一期重试 |

未校准概率不能解释为“长期真实胜率”；Paper 成交仍不能证明实际平台可成交。
当前行情不满足入场条件时显示具体原因，而不是制造订单让账户看起来活跃。

## 运行与隔离

- 地址：`http://127.0.0.1:8791/#bot`，状态接口仍为 `GET /api/hengzhun`。
- `data/hengzhun-v1-pilot/seed/`：不可变的种子、清单和误差样本。
- `data/hengzhun-v1-pilot/paper.sqlite3`：新 Paper 钱包、订单、成交、决策、运行价格及结果证据。
- `data/hengzhun-v1/`：旧采集数据库与严格模型原样保留，不清空、不复制大库。
- 启用试验后旧全量 RECORD 观察器不再启动，改为记录本次 Paper 所需的价格和决策/执行证据，避免原积压继续拖慢处理。
- `POLYBOT2OTHER_HENGZHUN_PILOT_ENABLED=true` 为启动脚本默认值；显式设为 `false` 才恢复原严格 RECORD。
- 种子摘要改变时必须建立新试验目录；不会在已运行账本内偷偷更换先验参数。
- 原四策略、双翼及实盘各自钱包和开关保留；该模块不加载 signer、不提供实盘订单 API。
