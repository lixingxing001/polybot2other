# 双翼配对 V1

这是无需训练的独立 Paper 策略，标识 `PAIRED_MAKER_V1`。它与衡准的 RECORD / 校准模型无关，也不继承原四个账户的资金。界面在策略列表和独立面板展示，地址 `http://127.0.0.1:8791/#bot`。

## 策略规则

| 项目 | 默认行为 |
|---|---|
| 本金 | 独立模拟 $100，重启不重置 |
| 每组预算 | 双边买入合计最多 $5，包含主动补齐费用；不是每侧 $5 |
| 入场窗口 | 开盘15秒之后，剩余时间至少60秒 |
| 被动报价 | 分别读取两侧真实买盘报价；总价最多 $0.98/份，不虚构另一侧盘口 |
| 价格范围 | 两侧报价均在 $0.15–$0.85；单侧买卖差价不超过 $0.04 |
| 数量 | 按预算向下取整，提交前满足当前市场最小份额；不足时不擅自加预算 |
| 每期资格 | 每期最多一组成交；没有成交时允许撤单后重报 |
| 报价管理 | 12秒到期重新排队；一侧被 post-only 拒绝则撤回另一侧 |
| 单边风险 | 单边持续12秒后撤回原报价，已确认份额优先尝试含费配平，否则限价退出 |
| 补齐条件 | 配平后的每份总成本最多 $0.995，且不超本组预算和可用现金 |
| 退出失败/小额余量 | 最多3次主动修复；不足最低份额或接近终局时保留真实余量等待官方结果 |
| 并行市场 | 最多5个；本策略过去24小时已实现净亏损额度默认 $10，按时间滚动恢复 |

Paper 开关、每组预算、并行市场数和日亏损额度可在面板修改。关闭只停止新报价，已有份额继续管理；也遵守顶部全局 Paper / BTC 暂停。原四策略设置不会被这些控件修改。

## 成交与资金口径

- 新委托、撤单各假设2秒传输时间。Maker 在到达时若会吃单，则按 post-only 拒绝；双边各自判断，不能当作原子成交。
- Maker 初始排队量为到达时同价可见买单。更早的盘口缩量可给前方队列设置保守上界；队列减少本身绝不记成交。
- 普通被动撮合使用实际收到的 `last_trade_price` SELL 事件：先消耗前方排队，再最多参与剩余观察成交量的25%。同毫秒成交造成的盘口变化不能被用来重复扣减队列；重复消息幂等。
- v1.2 增加不利穿价处理：若有效卖盘严格低于已生效的模拟买价，假设订单存在会改变真实成交带，不能因为原成交带缺少对应卖出就白白躲过风险。按原买价（较差价）和25%可见对手深度模拟成交，同一价格深度不重复使用；明确标为 `ASK_THROUGH_CONSERVATIVE`。同价触及、订单生效前或撤单生效后的盘口不能触发这一处理。
- Maker 费用为当前公开 `takerOnly` 规则下的0，返佣和奖励均按0计入。主动补齐/退出按当期公开费率逐档计算，费用向上取到五位小数。
- 主动订单到达时只使用提交之后、到达之前已收到的有效盘口，最多用25%可见深度。没有可验证到达盘口时不补造成交。
- 撮合买入立即占用模拟现金；12秒后确认，份额才可退出或合并。卖出现金在确认后到账。未确认的卖出回款作为应收估值，不重复记盈利。
- 撤单保留原报价截止时刻，并留出源消息延迟和处理时间，以接收撤单前已经发生的成交；资金不会先释放再被迟到消息重复使用。
- 只有两侧等量且已确认的份额才能模拟合并；每对回款$1，成本单独核销，60秒后变为可用现金。剩余单边份额必须等待同一 condition、同一 token 映射的官方最终0/1结果；要求 `closed=true` 和 `umaResolutionStatus=resolved`。
- 盈利占比按已完成且发生过成交的市场计算，不将未成交周期当作赢单。净值包含现金、配对价值、真实买盘扣费后的单边估值和应收。缺盘口时净值显示未知/上次有效估值，曲线不填零。

这些是公开行情驱动的排队/延迟假设，不是用户真实订单的成交回执。市场会因假设订单存在而改变的影响、真实排队位置和链上失败不能完全还原。界面完整保留数据中断标记和亏损；不能把短期模拟盈利当作稳定收益证明。

## 数据来源和隔离

只读复用原 CLOB 行情的最后成交与连接状态观察器；不额外复制所有高频盘口变动。只保存会影响活动委托的 SELL 消息、到达时盘口、委托/成交/现金事件，避免再次建立高负载全量采集器。

费用、精度、最低份额由公开 `clob-markets` 与 Gamma 市场核对。Gamma 精度滞后时，额外核对两个真实 token 的 CLOB book，采用共同有效的精度与最低量；未知费用不填0。查询终局使用 `/markets/slug/{slug}`，避免默认只列活动市场的列表端点遗漏已关闭市场。

代码没有 signer、交易 SDK 或真实资金操作接口；公开 HTTP 仅调用 GET。`data/paired-paper-v1/paper.sqlite3` 保存独立账本。新增/只读接口：

- `GET /api/paired-paper`
- `POST /api/paired-paper/settings`：仅本机、同源、JSON及独立控制令牌；拒绝任何实盘字段。

启动：`./start-macos.sh`。`POLYBOT2OTHER_PAIRED_PAPER_ENABLED` 默认 true，可用 false 单独关闭服务组件。保存的 Paper 配置与账本均保留。进程重启后取消缺少连续行情证据的模拟委托，标记数据间断；已知成交继续确认和结算，不把它们变回“零成交”。
