命名规则

SINGLE

单边策略。根据 BTC 当前价相对官方目标价 target_price 的方向，只买 Up 或 Down 中的一边。

核心门槛包括目标价存在、价格新鲜、盘口新鲜、离目标价距离、最大入场价、价差、深度、置信度和 edge。

PAIR

双边配对策略。同时买 Up 和 Down，重点看两边合成成本是否低于 1，靠折价配对、提前平仓或结算回收利润。

PAIR 会占用两个方向的持仓槽，且有残余库存止损、尾盘强平和日内回撤阈值。

REAL

实盘租户。SINGLE_FAK_REAL 是真实调用 Polymarket CLOB 的账户，走独立数据库和实盘开关。

它有独立预算、凭证、余额/授权检查、地理限制检查、进程锁、官方挂单检查和手动卖出流程。

字段 值 含义
订单类型 FAK Fill And Kill。按限价立即吃可成交盘口，成交多少算多少，剩余取消。更接近 taker 实盘。
订单类型 GTC Good Till Cancel。挂单一直保留到被成交、取消或市场结束，属于 maker 模拟。
订单类型 GTD Good Till Date。限时挂单，当前 Paper 用配置的过期秒数控制，适合观察 5 分钟市场挂单机会。
订单类型 POST_ONLY 只允许 maker。若限价会立即吃到卖一，则拒单，用来测试不吃流动性的挂单路径。
单边开仓模式 LEGACY 历史默认模式。同一市场已有反向仓时，允许再开新方向；这不是严格止损，只是双边反转采样。
单边开仓模式 STRICT 同一市场只允许一个方向仓，有任何同市场持仓或挂单都不再开新方向。适合小资金保守候选。
单边开仓模式 REVERSAL 允许反向双边买入，但会显式标记反转原因，便于单独统计反转腿胜率、PnL 和资金占用。
单边开仓模式 STOP_AND_FLIP 真正止损反手。先按旧方向 bid 平掉旧仓，再买新方向；新方向不可成交时保留旧仓。
行情模式 BASE 基础模式。主要用 Chainlink 当前价，缺失时按混合价格源规则可 fallback。
行情模式 MULTI_CONFIRM OKX/Binance 残差确认。外部残差与候选方向明显相反时过滤，不主动增强信号。
行情模式 MULTI_LEAD OKX/Binance 残差领先修正。用外部残差微调置信度，尝试捕捉外部现货领先 Chainlink 的情况。
价格源模式 MIXED 默认模式。优先 Chainlink；缺少时允许 fallback 到其他公共价格。
价格源模式 CHAINLINK_ONLY 只用新鲜 Chainlink。缺少或过期时不交易，用于隔离 fallback 噪音。
价格源模式 FALLBACK_ONLY 只在没有新鲜 Chainlink 时采样 fallback；有新鲜 Chainlink 时主动不交易。负面对照，不应实盘。
防守过滤 ANTI_BOT_GUARD Paper-only 防守采样。只过滤原本已通过的候选单，不做诱导盘口，也不接实盘。

22 个 Paper 策略组合说明

阅读方式：优先看 variant_id，它是数据库和接口里的稳定标识；combo 是 dashboard 展示名。 “建议用途”只代表当前开发定位，不代表长期结论。真正是否可实盘，需要等样本、回撤和订单质量复盘。
# variant_id combo 类型 含义 适用场景 实盘态度
1 SINGLE_FAK SINGLE + FAK 基线 当前单边 FAK Paper 基线。按目标价方向买一边，允许历史 legacy 反向双边开仓。 所有单边变体的对照组；也是当前实盘接入的行为基础。 已映射到 SINGLE_FAK_REAL，但实盘仍受独立风控和开关控制。
2 SINGLE_FAK_REVERSE SINGLE + FAK Reverse 方向反向对照 先按 SINGLE_FAK 生成原始 Up/Down 信号，再把最终下注方向反过来；原因里标记 SINGLE_REVERSE。 压力测试基线方向判断是否存在系统性反向价值，并单独观察反向下注样本。 Paper-only，对真实资金风险极高；必须先看样本胜率、PnL、回撤和盘口成交质量。
3 SINGLE_FAK_AGGRESSIVE_EDGE SINGLE + FAK Aggressive Edge 激进入场过滤 基于旧组合样本暴露出的价格带和 bps 区间，对基线信号做后置过滤；原因里标记 SINGLE_AGGRESSIVE_EDGE。 优先验证低价高 edge、6-8bps 甜点区、极高置信高价单能否形成新的正收益样本。 已映射到 SINGLE_FAK_AGGRESSIVE_EDGE_REAL，真实下单仍走独立 live 账户、预检和开关控制。
4 SINGLE_FAK_CHAINLINK_ONLY SINGLE + FAK CHAINLINK_ONLY 价格源实验 单边 FAK，但只允许用新鲜 Chainlink 价格开仓，缺失或过期时不 fallback。 判断 fallback 是否带来噪音；适合和 SINGLE_FAK 对比。 候选观察，不应直接替换实盘，需先看样本覆盖率和错过机会。
5 SINGLE_FAK_ANTI_BOT_GUARD SINGLE + FAK CHAINLINK_ONLY ANTI_BOT_GUARD 防守采样 基于 Chainlink-only 的单边 FAK，额外过滤外部价格反向、合约偏贵但锚定弱、薄盘口高价等疑似异常单。 验证“疑似被机器人或盘口噪音诱导时少下单”是否能改善回撤。 Paper-only，实盘禁止直接沿用；采样后再决定是否拆规则。
6 SINGLE_FAK_FALLBACK_ONLY SINGLE + FAK FALLBACK_ONLY 负面对照 只在没有新鲜 Chainlink 时使用 fallback 价格；有 Chainlink 时不交易。 专门观察 fallback 单独开仓的质量，判断 fallback 是否应该被限制。 严禁实盘，定位是负面对照和采样。
7 SINGLE_FAK_MULTI_CONFIRM SINGLE + FAK MULTI_CONFIRM 外部确认 单边 FAK，要求 OKX/Binance 基差残差至少有可用样本；若残差明显反向则过滤。 验证外部现货是否能减少错误方向单。 未验证，不接实盘；若长时间不下单，多半是外部基差样本未 ready 或过滤过严。
8 SINGLE_FAK_MULTI_LEAD SINGLE + FAK MULTI_LEAD 领先修正 单边 FAK，用 OKX/Binance 残差对置信度做小幅加减，尝试捕捉外部现货领先 Chainlink。 验证你观察到的 OKX/Binance 先动、Chainlink 后动是否有统计价值。 高不确定实验，不接实盘；要先看是否只是交易所固定基差造成错觉。
9 SINGLE_FAK_STRICT SINGLE + FAK STRICT 保守候选 单边 FAK，同一市场只允许一个方向仓；已有任何同市场仓位或挂单就不再反向开仓。 小资金保守模式，控制单个 5 分钟市场里双边占用资金的问题。 可作为未来实盘候选，但当前实盘仍是 SINGLE_FAK_REAL 的 legacy 行为。
10 SINGLE_FAK_REVERSAL SINGLE + FAK REVERSAL 反转实验 允许同一市场反向再买，但显式标记 SINGLE_REVERSAL，方便统计反转腿。 复盘反向双边买入到底是在止损、加仓，还是贡献额外收益。 不是实盘止损逻辑；不应当作风险关闭手段。
11 SINGLE_FAK_STOP_AND_FLIP SINGLE + FAK STOP_AND_FLIP 止损反手 新方向信号出现时，先检查新方向可成交，再用旧方向 bid 平旧仓，然后买新方向。 验证真正止损反手是否优于 legacy 反向双边买。 高风险实验；实盘前必须验证滑点、bid 深度、重复提交和未成交处理。
12 SINGLE_GTC SINGLE + GTC 挂单实验 单边方向判断不变，但用 GTC maker 挂单等待成交。 观察不吃流动性时能否降低成本，代价是可能错过行情。 仅 Paper。实盘 maker 需要更完整的撤单、排队和库存管理。
13 SINGLE_GTD SINGLE + GTD 限时挂单 单边方向判断不变，但挂单只保留一段时间，过期后释放预留资金。 适合 5 分钟市场里测试“挂一会儿，不追价”的执行方式。 仅 Paper，实盘前需要官方订单生命周期和撤单确认。
14 SINGLE_POST_ONLY SINGLE + POST_ONLY maker 实验 单边 maker-only，若限价会立即吃到卖一则拒单；成交依赖后续盘口移动和队列模拟。 测试纯 maker 是否能减少成本。 仅 Paper，当前 maker 队列是模拟，不等于官方真实排队位置。
15 REALTIME_MAKER_POST_ONLY REALTIME MAKER + POST_ONLY MULTI_LEAD 实时做市采样 Paper-only 实时 fair value 做市实验。用 WebSocket 实时方向概率作为 fair value，地址修正概率只作为慢速修正；只挂 POST_ONLY，已放宽 TTL/edge 并加入年轻挂单保护，避免还没排队就被轻微 edge 波动撤掉。 验证“实时概率 + maker 挂单”是否能形成有效成交、赚 spread/流动性，而不是被更快机器人挑单。 严禁直接接实盘。必须先复盘 maker fill rate、adverse selection、撤单次数、成交后胜率和 PnL。
16 LLM_SUPER_AGENT_PAPER LLM SUPER AGENT + PAPER 智能路由采样 Paper-only 超级下注智能体实验。非阻塞调用 LLM 生成策略包；实时执行仍走本地快脑和现有 FAK/STOP_AND_FLIP/REVERSAL/PAIR_FAK 等确定性路径。 验证 LLM 是否能根据盘型动态选择组合，并长期优于单一最强组合。 严禁直接接实盘。LLM 只能做路由建议，不能绕过硬风控。
17 PAIR_FAK PAIR + FAK 配对 taker 同时买 Up 和 Down，要求双边合成成本低于阈值，并检查含费成本是否仍有毛边。 配对策略的 taker 对照组，也可观察补单和应急处理。 不接实盘。双边 taker 对深度和手续费极敏感。
18 PAIR_FAK_MULTI_CONFIRM PAIR + FAK MULTI_CONFIRM 配对确认 PAIR_FAK 加 OKX/Binance 基差样本 ready 门槛；缺样本时不开仓。 观察外部现货确认是否能减少不合理配对开仓。 不接实盘；样本不足时可能长时间没有订单。
19 PAIR_FAK_MULTI_LEAD PAIR + FAK MULTI_LEAD 配对领先 PAIR_FAK 加 OKX/Binance 残差采样说明，用于观察外部领先信号对配对是否有帮助。 配对维度的外部价格领先实验。 不接实盘；当前更多是采样标签和开仓门槛实验。
20 PAIR_GTC PAIR + GTC 配对核心候选 双边配对 maker 挂单，Up/Down 同时挂，等待低成本成交。 历史定位是核心候选，用于测试低合成成本机会。 仍是 Paper。实盘前要处理官方挂单撤单、单边成交残余和资金占用。
21 PAIR_GTD PAIR + GTD 5m 核心候选 PAIR_GTC 的限时版本，尤其适合 5 分钟市场，避免挂单无限等待。 测试短周期里双边限时挂单的成交和回撤表现。 Paper 候选。实盘必须先验证限时撤单和残余库存处理。
22 PAIR_POST_ONLY PAIR + POST_ONLY 配对 maker 目标 双边配对的纯 maker-only 版本，理论上最能控制吃单成本，但成交最不确定。 用于观察极致 maker 成本控制是否有长期优势。 Paper 目标，不是当前实盘方案。

按场景快速选择

你想看什么 优先看哪些组合 判断重点
当前单边策略是否还行 SINGLE_FAK、SINGLE_FAK_AGGRESSIVE_EDGE、SINGLE_FAK_CHAINLINK_ONLY 胜率、PnL、回撤、fallback 是否拉低表现，以及激进过滤是否提高净盈亏。
基线方向判断是否可能反着做更好 SINGLE_FAK、SINGLE_FAK_REVERSE 同一信号窗口下的方向反差、成交价、胜率、PnL 和回撤。
小资金是否要禁止反向双边买 SINGLE_FAK、SINGLE_FAK_STRICT、SINGLE_FAK_REVERSAL 反转腿贡献、资金占用、同市场双边单最终胜负。
真正止损反手有没有必要 SINGLE_FAK_REVERSAL、SINGLE_FAK_STOP_AND_FLIP 平旧仓损失、反手后收益、bid 深度导致的滑点。
OKX/Binance 是否能提高准确率 SINGLE_FAK_MULTI_CONFIRM、SINGLE_FAK_MULTI_LEAD、PAIR_FAK_MULTI_CONFIRM、PAIR_FAK_MULTI_LEAD 样本 ready 比例、过滤掉的单原本盈亏、残差是否存在真实领先价值。
机器人/盘口异常防守是否有效 SINGLE_FAK_CHAINLINK_ONLY、SINGLE_FAK_ANTI_BOT_GUARD 少下了多少单、被过滤单原本盈亏、回撤是否下降、是否误杀盈利单。
PAIR 配对是否有长期价值 PAIR_FAK、PAIR_GTC、PAIR_GTD、PAIR_POST_ONLY 合成成本、含费成本、双边是否一起成交、残余库存损失。
LLM 智能体是否能超过单一组合 LLM_SUPER_AGENT_PAPER、SINGLE_FAK_STOP_AND_FLIP、SINGLE_FAK_REVERSAL、PAIR_FAK LLM 路由选择、是否采纳、最终 PnL、是否只是在过度交易或过度避险。
准备实盘流程打通 SINGLE_FAK_REAL 凭证、钱包余额/授权、官方挂单、地理限制、软件预算、最小订单、PENDING 对账。

实盘边界

当前实盘租户包括 SINGLE_FAK_REAL 和 SINGLE_FAK_AGGRESSIVE_EDGE_REAL。它们走独立 live 数据库和实盘开关管理的真实交易路径。

SINGLE_FAK_REAL 按 SINGLE_FAK 基线接入：FAK taker 买入，legacy 同市场反向双边买入行为保留。SINGLE_FAK_AGGRESSIVE_EDGE_REAL 在同一套 live FAK 路径前增加 Aggressive Edge 共用过滤器。STRICT、REVERSAL、STOP_AND_FLIP、MULTI_CONFIRM、MULTI_LEAD、ANTI_BOT_GUARD、LLM_SUPER_AGENT_PAPER 和所有 PAIR 组合都没有自动接入实盘。

尤其注意：SINGLE_FAK_FALLBACK_ONLY 和 SINGLE_FAK_ANTI_BOT_GUARD 明确是 Paper-only 采样，不应直接套到实盘。

建议复盘顺序

优先级 复盘问题 涉及组合
1 单边基线最近亏损是否来自价格带、fallback、反向双边、还是盘口执行质量。 SINGLE_FAK、SINGLE_FAK_AGGRESSIVE_EDGE、SINGLE_FAK_CHAINLINK_ONLY、SINGLE_FAK_FALLBACK_ONLY
2 同市场反向买入到底贡献收益还是扩大回撤。 SINGLE_FAK、SINGLE_FAK_REVERSE、SINGLE_FAK_STRICT、SINGLE_FAK_REVERSAL、SINGLE_FAK_STOP_AND_FLIP
3 OKX/Binance 的领先感是否能被残差样本证明。 MULTI_CONFIRM、MULTI_LEAD 相关组合
4 ANTI_BOT_GUARD 是否只是少交易，还是确实过滤掉了坏单。 SINGLE_FAK_CHAINLINK_ONLY、SINGLE_FAK_ANTI_BOT_GUARD
5 PAIR maker 是否能稳定减少成本，同时避免单边残余。 PAIR_GTC、PAIR_GTD、PAIR_POST_ONLY
